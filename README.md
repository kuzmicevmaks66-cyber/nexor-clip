# NEXOR CLIP

Настольное приложение для Windows 10/11 x64: монтаж коротких видео, субтитры, реклама и аналитика YouTube / TikTok.
Стек: **Tauri 2 · React · TypeScript · Vite · Rust · FFmpeg · SQLite · whisper.cpp**.
Все данные хранятся локально. Облачные сервисы, Firebase и платные backend-сервисы не используются.

---

## Готовый установщик «скачал → нажал → работает» (рекомендуется)

Установщик собирается бесплатно на серверах GitHub, на вашем компьютере ничего ставить не нужно. В него встраиваются **FFmpeg, whisper.cpp и модель распознавания речи (small)**, а WebView2 при необходимости ставится автоматически.

1. Зарегистрируйтесь на https://github.com.
2. Справа вверху нажмите **«+» → New repository**, введите имя `nexor-clip` и нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** папки `nexor-clip`, включая папку `.github`. Затем нажмите **Commit changes**.
4. Откройте вкладку **Actions** → **«Сборка установщика Windows»** → **Run workflow** → **Run workflow**.
5. Подождите 15–25 минут, пока появится зелёная галочка. Откройте **Releases** справа на главной странице репозитория и скачайте **`NEXOR-CLIP-Setup.exe`**.
6. Запустите `NEXOR-CLIP-Setup.exe` → «Установить» → откройте NEXOR CLIP с ярлыка. Указывать пути к FFmpeg и Whisper не нужно.

Если папка `.github` не загрузилась (Windows скрывает папки с точкой), сделайте так:
- **Actions** → **set up a workflow yourself**;
- вставьте содержимое файла `.github/workflows/build-windows.yml`;
- нажмите **Commit changes**.

## 0. Сборка на своём компьютере: собрать установщик в один клик

1. Распакуйте архив в папку **без кириллицы и пробелов** в пути, например `C:\nexor-clip`.
2. Дважды щёлкните **`BUILD-INSTALLER.bat`**. Скрипт:
   - сам установит Node.js, Microsoft C++ Build Tools и Rust (через winget), если их нет;
   - соберёт установщик вне OneDrive (в папке `nexor-build` на самом свободном диске) и положит `NEXOR CLIP_1.0.0_x64-setup.exe` на рабочий стол. При ошибке выведет первую ошибку и сохранит журнал `build-log.txt`.

   Первый раз это занимает 15–30 минут. Если Windows попросит перезагрузку после установки Build Tools, перезагрузитесь и запустите `.bat` ещё раз.
3. Запустите `NEXOR CLIP_1.0.0_x64-setup.exe` → «Далее» → «Установить». Права администратора не нужны.
4. Откройте **NEXOR CLIP** через ярлык на рабочем столе или меню «Пуск».

Если SmartScreen пишет «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает, потому что установщик не подписан сертификатом.

**Сборка в облаке без установки инструментов.** Загрузите проект в свой репозиторий GitHub. Откройте вкладку **Actions** → «Сборка установщика Windows» → **Run workflow**. Через ~15 минут готовый `.exe` появится в разделе **Artifacts** этого запуска.

## 1. Что нужно установить (ручная сборка) (один раз)

| Инструмент | Версия | Где взять |
|---|---|---|
| Node.js | 20 LTS или новее | https://nodejs.org |
| Rust (MSVC) | 1.77+ | https://rustup.rs, затем `rustup default stable-msvc` |
| Microsoft C++ Build Tools | 2022 | Visual Studio Installer → «Разработка классических приложений на C++» |
| WebView2 Runtime | любая | Уже есть в Windows 10/11 |
| FFmpeg (полная сборка) | 6+ | https://www.gyan.dev/ffmpeg/builds/ → `ffmpeg-release-full.7z` |
| whisper.cpp | 1.7+ | https://github.com/ggml-org/whisper.cpp/releases → `whisper-bin-x64.zip` |
| Модель Whisper | — | https://huggingface.co/ggerganov/whisper.cpp → `ggml-small.bin` (для русского) или `ggml-medium.bin` |

### FFmpeg
1. Распакуйте архив, например в `C:\Tools\ffmpeg`.
2. Либо добавьте `C:\Tools\ffmpeg\bin` в PATH, либо укажите путь к `ffmpeg.exe` в «Настройки → FFmpeg».
3. В «Настройках» должны гореть отметки **libx264** (экспорт H.264) и **libass** (вшивание субтитров).

### whisper.cpp
1. Распакуйте `whisper-bin-x64.zip`, например в `C:\Tools\whisper`.
2. В «Настройки → Субтитры» укажите `whisper-cli.exe` и файл модели `ggml-*.bin`.
3. Распознавание работает полностью офлайн.

## 2. Запуск и сборка

```powershell
cd nexor-clip
npm install
npm run app:dev      # запуск приложения в режиме разработки
npm run app:build    # сборка установщика .exe
```

При ручной сборке установщик появится в `src-tauri\target\release\bundle\nsis\NEXOR CLIP_1.0.0_x64-setup.exe`. Через `BUILD-INSTALLER.bat` он сразу копируется на рабочий стол.

Первая сборка Rust занимает 5–15 минут. `npm run dev` открывает только интерфейс в браузере, без доступа к файлам и API. Для работы нужен `npm run app:dev`.

## 3. Ключи API (вводятся в приложении)

Ключи **не хранятся в коде и не попадают во frontend**. Их вводят в «Настройках», а Rust-часть сохраняет их в **Windows Credential Manager**. Интерфейс видит только отметку «сохранено».

### YouTube: Google Cloud Console
1. Откройте https://console.cloud.google.com/ и создайте проект.
2. В «APIs & Services → Library» включите:
   - **YouTube Data API v3**
   - **YouTube Analytics API**
3. **API-ключ** (поиск и публичные каналы): «Credentials → Create credentials → API key». Желательно ограничить ключ API «YouTube Data API v3». Вставьте его в «Настройки → YouTube → API-ключ».
4. **OAuth** (свой канал, аналитика, загрузка видео):
   - На экране «OAuth consent screen» выберите тип External, затем добавьте свой Google-аккаунт в **Test users**.
   - Создайте «Credentials → Create credentials → OAuth client ID», тип **Desktop app**.
   - Скопируйте **Client ID** и **Client Secret** в «Настройки → YouTube».
   - Redirect URI для Desktop-клиента регистрировать не нужно: приложение использует loopback `http://127.0.0.1:3456/callback` с PKCE.
5. Нажмите «Подключить канал». Откроется браузер со входом Google.

Запрашиваемые разрешения:
- `youtube.readonly`
- `yt-analytics.readonly`
- `youtube.upload`, которое используется только при публикации по вашей команде.

### TikTok: TikTok for Developers
1. Откройте https://developers.tiktok.com/, создайте приложение и выберите платформу **Desktop**.
2. Добавьте продукты:
   - **Login Kit**
   - **Display API** (если доступен отдельно)
   - **Content Posting API** (только если нужна публикация)
3. Укажите Redirect URI: `http://127.0.0.1:3455/callback/` (с завершающим `/`).
4. Запросите scopes:
   - `user.info.basic`, `user.info.profile`, `user.info.stats`, `video.list`
   - `video.publish`, если нужна публикация
5. Скопируйте **Client Key** и **Client Secret** в «Настройки → TikTok».
6. Для публикации включите «Разрешить публикацию» и переподключите аккаунт.

Ограничения TikTok:
- Пока приложение не прошло аудит TikTok, вход работает только для аккаунтов, добавленных в Sandbox / Target users.
- Пока приложение не прошло аудит, Content Posting API публикует только с приватностью «Только я».

Если порт 3455 или 3456 занят, поменяйте его в «Настройках» и обновите Redirect URI в консоли разработчика.

## 4. Возможности

При запуске открывается окно **«Аккаунты YouTube и TikTok»** с двумя карточками. В каждой можно сразу войти через официальный OAuth в браузере, ввести ключи приложения при первом запуске, выйти или перейти в раздел. Окно также открывается кнопкой «Аккаунты» в верхней панели. Показ при запуске отключается галочкой.


| Раздел | Что делает |
|---|---|
| Главная | Приветствие, реальные счётчики (проекты, экспорты, обработанные видео), последние проекты, быстрые переходы |
| YouTube | Поиск видео и каналов (Data API v3), официальный IFrame-плеер, ручной выбор фрагмента (начало, конец, длительность, позиция, предпросмотр интервала), сохранение ссылки и интервала в проект, отслеживание каналов |
| TikTok | Вход через OAuth, профиль и видео с метриками из API. Чего API не возвращает, помечено «Недоступно через API» |
| Аналитика | Подписчики, просмотры, количество видео. Отчёт YouTube Analytics по дням (views, likes, comments, shares, subscribersGained и др.) и страница видео. Локальная история снимков для трендов, графики, кнопка «Обновить», время обновления |
| Видеоредактор | Импорт видео, аудио и изображений; Timeline с дорожками; обрезка краёв; разрезание (S); удаление (Delete); порядок фрагментов; 9:16 / 16:9 / 1:1; заполнение, вписывание или размытый фон; громкость; фоновое аудио; наложения; undo/redo; предпросмотр через FFmpeg; экспорт |
| Субтитры | Whisper RU/EN/авто, редактирование текста и таймингов, разделение и объединение, сдвиг всех реплик, импорт и экспорт SRT, шрифт, размер, цвет, обводка, тень, позиция, анимации (fade / pop / по словам), предпросмотр поверх кадра |
| Реклама | Локальная библиотека (видео, изображения, логотипы), категории, переименование, удаление из библиотеки (файл остаётся), просмотр, добавление на Timeline, автоматическая расстановка (подробнее ниже) |
| Мои проекты | Создание, открытие, переименование, дублирование, удаление (исходники не трогаются), импорт `.nexorclip`, даты создания и изменения |
| Экспорт | MP4 H.264 + AAC; 480p–4K; 24–60 FPS; качество (CRF); папка; прогресс; отмена; понятные ошибки; затем по желанию публикация на YouTube или в TikTok |
| Настройки | Папки, FFmpeg и ffprobe, whisper.cpp и модель, ключи YouTube и TikTok, локальные данные (размер, очистка кэша и истории), о программе |

Автоматическая расстановка рекламы:
- Работает по правилам: только на склейках и в паузах речи (FFmpeg silencedetect).
- Никогда не ставит рекламу внутрь реплики субтитров.
- Учитывает минимальный интервал, лимит вставок и отступы от начала и конца.
- План можно отредактировать до применения, а результат — на Timeline.

Горячие клавиши редактора:

| Клавиша | Действие |
|---|---|
| `Пробел` | Пуск / пауза |
| `S` | Разрезать |
| `Delete` | Удалить выделенное |
| `←` / `→` | Шаг на кадр (с `Shift` — на 1 с) |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / повторить |

## 5. Где хранятся данные

- **База SQLite** (`nexor.db`) лежит в `%APPDATA%\com.nexor.clip\`. В ней проекты, настройки, библиотека рекламы и снимки аналитики.
- **Копии проектов** `.nexorclip` по умолчанию лежат в `Документы\NEXOR CLIP\Projects`.
- **Экспорт** по умолчанию идёт в `Видео\NEXOR CLIP`.
- **Секреты** хранятся в Windows Credential Manager под именем `com.nexor.clip`.
- Проекты хранят только **пути** к исходникам. Файлы не копируются, не изменяются и не удаляются.

## 6. Принципы

- Никаких демо-данных и имитаций. Если API не отдаёт метрику, так и написано.
- Только официальные API: YouTube Data v3, YouTube Analytics, TikTok Login Kit, Display API и Content Posting API. Закрытая статистика не собирается.
- Видео YouTube воспроизводится только через официальный IFrame Player и не скачивается.
- Рекламные материалы не загружаются из интернета. Используются только ваши локальные файлы.
- Публикация происходит только по явному действию пользователя в окне экспорта.

## 8. Если что-то не работает

| Проблема | Решение |
|---|---|
| «FFmpeg не найден» | Укажите путь к `ffmpeg.exe` в Настройках |
| Нет libass или libx264 | Установите полную (full) сборку FFmpeg |
| Ошибки Google `accessNotConfigured` | В Google Cloud не включён YouTube Data API v3 или YouTube Analytics API |
| Google `access_denied` | Добавьте свой аккаунт в Test users на экране OAuth consent |
| TikTok `redirect_uri` mismatch | Redirect URI в консоли TikTok должен совпадать посимвольно: `http://127.0.0.1:3455/callback/` |
| Ошибка компиляции Rust | Выполните `rustup update`, установите C++ Build Tools, повторите `npm run app:dev` |
